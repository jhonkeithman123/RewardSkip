# Generic recipe schema

Recipes let you teach RewardSkip a new rewarded-ad API without rebuilding the APK. They live in:

```
/data/local/tmp/rewardskip_generic.json
```

The file is read once when a scoped app starts. Restart the game after editing it.

---

## Top level

```json
{
  "version": 1,
  "recipes": [ ... ]
}
```

Lines starting with `//` are ignored, so you can comment the file. The `version` field is
currently informational (must be `1`).

---

## Recipe fields

| Field | Type | Required | Default | Meaning |
|---|---|---|---|---|
| `name` | string | no | `?` | Label used in log messages — useful for debugging |
| `enabled` | bool | no | `true` | `false` skips this recipe entirely |
| `class` | string | **yes** | — | Ad class whose `showMethod` is cancelled |
| `showMethod` | string | no | `show` | Method that starts the ad |
| `loadClass` | string | no | — | Callback class used to capture the ad object |
| `loadMethod` | string | no | `onAdLoaded` | Method on `loadClass` that receives the ad |
| `listenerSetter` | string | no | — | Method on `class` that receives the callback/listener object |
| `callbacks` | array | **yes** | — | Methods to fire after cancelling `showMethod` |
| `rewardClass` | string | no | — | Class holding a default reward object |
| `rewardField` | string | no | — | Static field on `rewardClass` (read via reflection) |
| `rewardMethod` | string | no | — | Static no-arg factory on `rewardClass`, used when `rewardField` is absent |
| `argIndex` | int | no | `0` | Only inside a callback with `"on": "arg"` — which `show()` argument to use |

### Callback object

| Field | Type | Meaning |
|---|---|---|
| `method` | string | Method name to invoke |
| `on` | string | Where to invoke it: `listener` (default), `ad`, or `arg` |
| `arg` | string | Argument to pass: `reward`, `ad`, or omitted for no arguments |
| `argIndex` | int | Which `show()` argument to use when `on` is `arg` |

`on` values:

- **`listener`** — object captured by `listenerSetter`
- **`ad`** — object captured by `loadClass`/`loadMethod`
- **`arg`** — one of the arguments passed to `showMethod`, selected by `argIndex`

`arg` values:

- **`reward`** — the object from `rewardClass`/`rewardField` or `rewardMethod`
- **`ad`** — the captured ad object
- omitted — call the method with no arguments

## Minimal example

```json
{
  "version": 1,
  "recipes": [
    {
      "name": "my game custom SDK",
      "class": "com.example.ads.RewardAd",
      "showMethod": "show",
      "listenerSetter": "setListener",
      "callbacks": [
        { "method": "onAdDisplayed", "on": "listener" },
        { "method": "onRewarded", "on": "listener" },
        { "method": "onAdClosed", "on": "listener" }
      ]
    }
  ]
}
```

## AdMob example (generated by the scanner)

```json
{
  "name": "AdMob / com.example.game",
  "enabled": true,
  "class": "com.google.android.gms.ads.rewarded.RewardedAd",
  "loadClass": "com.google.android.gms.ads.rewarded.RewardedAdLoadCallback",
  "loadMethod": "onAdLoaded",
  "listenerSetter": "setFullScreenContentCallback",
  "showMethod": "show",
  "rewardClass": "com.google.android.gms.ads.rewarded.RewardItem",
  "rewardField": "DEFAULT_REWARD",
  "callbacks": [
    { "method": "onAdShowedFullScreenContent", "on": "listener" },
    { "method": "onUserEarnedReward", "on": "arg", "argIndex": 1, "arg": "reward" },
    { "method": "onAdDismissedFullScreenContent", "on": "listener" }
  ]
}
```

Note `argIndex: 1`: AdMob's `show(Activity, OnUserEarnedRewardListener)` passes the reward
listener as the second argument.

## Generating recipes

```sh
python scripts/scan_target.py <package> --out recipe.json
```

The scanner fills in known SDK recipes and lists candidate reward classes from the game's own
package. Every generated recipe starts **disabled** — review method names before enabling.

Install the result:

```sh
adb push recipe.json /data/local/tmp/rewardskip_generic.json
```

## Debugging a recipe

Watch the framework log for:

- `RewardSkip generic recipe '<name>' failed: ...` — bad class or reflection error in setup
- `RewardSkip generic: callback <method> not found on <class>` — method name or target wrong
- `hooks=15/15` in the self-check — the generic hook constructor itself loaded

Common fixes:

| Problem | Fix |
|---|---|
| Ad still plays | `class` or `showMethod` wrong — check the Dex with the scanner output |
| Reward not credited | Missing `onAdDisplayed`/equivalent callback; add it first in `callbacks` |
| `callback ... not found` | Method name wrong, or `on` points at the wrong object |
| Null reward passed | `rewardClass`/`rewardField` (or `rewardMethod`) missing or inaccessible |

---

## Safety notes

- Recipes are **additive** to the built-in hooks. Enabling a recipe for an already-supported SDK
  can fire callbacks twice and produce duplicate rewards.
- A recipe can call any method on any object inside the game. Only use configs you trust.
- Server-side reward validation cannot be bypassed by any recipe.
